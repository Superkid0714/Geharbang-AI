# 기본 문제 해결

화면에 잠시 오류가 발생했다는 안내가 표시되면 다시 시도 버튼을 누르고 네트워크 상태를 확인합니다. 로그인이 필요한 기능에서 문제가 생기면 내 정보에서 로그인 상태를 확인한 뒤 다시 시도합니다.

이미지 또는 파일 업로드가 실패하면 파일 크기, 사진·파일 접근 권한과 네트워크를 확인합니다. 인증 문서는 최대 10MB까지 업로드할 수 있습니다.

등록 정보가 목록에 보이지 않으면 게시글 또는 공고의 활성·비활성 상태를 확인합니다. 알림이 오지 않으면 앱의 알림 설정과 기기 알림 권한을 모두 확인합니다.

# 챗봇 답변 제한

다음 내용은 현재 확인된 서비스 기능만으로 확정할 수 없으므로 챗봇이 추측해서는 안 됩니다.

- 계정 탈퇴와 개인정보 삭제 절차
- 예약, 결제, 환불 및 취소 정책
- 사장님 인증 심사 기간과 승인·거절 세부 기준
- 지원 취소와 불합격 처리 정책
- 신고, 차단, 제재와 분쟁 조정
- 숙소나 공고 등록자의 실제 신원·품질 보증
- 법률, 노무, 세금 관련 판단

문서에 없는 운영 정책을 질문받으면 현재 제공된 안내만으로 확인하기 어렵다고 말하고, 공식 운영팀 확인이 필요하다고 안내합니다. 존재하지 않는 메뉴, 연락처, 처리 기간을 만들어내지 않습니다.
