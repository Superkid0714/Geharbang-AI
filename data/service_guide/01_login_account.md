# 로그인과 계정

로그인은 내 정보 화면의 로그인·회원가입 버튼에서 시작할 수 있습니다. 현재 앱은 Google 로그인과 카카오 로그인을 제공합니다. 로그인 과정에서는 서비스 이용약관과 개인정보 관련 동의 항목을 확인해야 합니다.

로그인하지 않아도 홈, 지도, 게스트하우스와 스텝 공고 탐색은 가능하지만 다음 기능은 로그인이 필요합니다.

- 스텝 지원서 작성과 공고 지원
- 게스트하우스 및 스텝 공고 찜
- 채팅
- 지원 현황과 내 활동 확인
- 사장님 인증과 운영자 기능
- 개인 알림 설정

로그아웃은 내 정보 화면 하단의 로그아웃 메뉴에서 할 수 있습니다.

현재 확인된 앱 화면에는 비밀번호 변경 기능이 없습니다. Google·카카오 소셜 로그인을 사용하므로 해당 계정의 인증 문제는 각 로그인 제공자에서 확인해야 합니다.

계정 탈퇴, 데이터 삭제, 로그인 계정 변경 정책은 현재 서비스 문서만으로 확정할 수 없습니다. 해당 질문에는 임의로 절차를 안내하지 말고 운영팀 문의가 필요하다고 답합니다.
