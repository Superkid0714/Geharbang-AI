# 스텝 지원 방법

스텝 공고에 지원하려면 로그인과 내 지원서가 필요합니다. 내 정보의 지원서 작성 메뉴에서 지원서를 먼저 만들 수 있습니다.

지원서에는 대표 사진, 이름, 전화번호, 생년월일, 성별, 근무 시작 가능일, 근무 가능 요일, 자기소개, MBTI, 선택 입력인 Instagram과 나의 스타일 등이 포함됩니다. 이미 지원서가 있으면 내 정보에서 지원서 수정 또는 내 지원서 보기를 이용합니다.

공고 지원 순서는 다음과 같습니다.

1. 스텝 공고 상세 화면을 엽니다.
2. 지원 버튼을 선택합니다.
3. 지원서가 없으면 지원서 작성 화면으로 이동합니다.
4. 기존 지원서를 선택하고 사장님이 등록한 추가 질문에 답합니다.
5. 내용을 확인한 뒤 지원서를 제출합니다.

제출한 지원은 내 정보의 지원 내역에서 확인합니다. 지원 현황 화면은 전체와 합격 항목으로 나누어 볼 수 있으며, 각 항목에서 공고 상세로 이동할 수 있습니다. 합격 여부는 대기중 또는 합격 상태로 표시됩니다.

동일 공고 중복 지원은 제한될 수 있습니다. 이미 지원한 공고라는 안내가 나오면 내 정보의 지원 내역에서 기존 지원 상태를 확인합니다.

지원 취소, 지원서 열람 기간, 불합격 처리 기준은 현재 확인된 앱 문서만으로 확정할 수 없습니다. 임의로 정책을 안내하지 않습니다.
